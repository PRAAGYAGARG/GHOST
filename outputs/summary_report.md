# GHOST - Evaluation Summary Report

## Overview

This report summarises the evaluation of 5 location privacy
algorithms (3 proposed modifications + 2 baselines) on a synthetic
smart-city road network graph with 200 nodes and 80 IoT devices.

All metrics are measured on a **common physical scale (metres)**
following the adversary-grounded evaluation framework of
Shokri et al. (IEEE S&P 2011).

## Comparison Table

| Algorithm | Avg Err (m) | Max Err (m) | P95 Err (m) | Availability (%) | Adversary Err (m) |
|-----------|-------------|-------------|-------------|-------------------|-------------------|
| Base k-Anon | 94.9 | 848.74 | 456.84 | 100.0 | 25.73 |
| Dist-Bounded k-Anon | 90.69 | 783.04 | 433.1 | 100.0 | 27.73 |
| Adaptive k-Anon | 82.88 | 672.49 | 395.17 | 100.0 | 25.7 |
| Base DP | 728.71 | 3024.37 | 1808.73 | 100.0 | 209.57 |
| Clipped DP | 619.0 | 1309.96 | 1112.61 | 100.0 | 186.78 |

## Key Findings

- **Best Privacy**: Base DP (adversary error = 209.57 m)
- **Best Utility**: Adaptive k-Anon (avg location error = 82.88 m)

## Research Gaps Addressed

1. **Gap 1** (k-anon fails in sparse areas): Distance-bounded and adaptive
   k-anonymity maintain 100% availability even in sparse regions.
2. **Gap 2** (No common privacy scale): All algorithms are compared using
   the same adversary expected error metric (metres).
3. **Gap 3** (DP noise is unbounded): Clipped DP bounds worst-case error,
   shown by significantly lower max error compared to base DP.
4. **Gap 4** (Simple fixes vs complex ones): Our simple modifications
   (radius cap, k reduction, noise clipping) achieve substantial improvements
   without complex density-aware calculations.
